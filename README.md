# التحكم في البوابات

نظام ويب داخلي لتسجيل حركة الأفراد والمركبات والزائرين، وإدارة الإجازات والعيادات والفرق والمأموريات والمكاتبات، وإعداد التقارير اليومية. واجهة النظام عربية وتعمل من المتصفح.

## ابدأ من هنا

- [عرض النظام للإدارة](docs/عرض-النظام-للإدارة.md): ملخص الوظائف مع أمثلة ولقطات من نسخة عرض ببيانات خيالية.
- [دليل المستخدم](docs/دليل-المستخدم.md): استخدام صفحات العمليات والتقارير خطوة بخطوة.
- [دليل المسؤول والتشغيل](docs/دليل-المسؤول-والتشغيل.md): المستخدمون والإعدادات والتثبيت والنسخ الاحتياطي واستكشاف الأعطال.

## تشغيل سريع للمطور

يتطلب تشغيل نسخة التطوير Node.js 22.12 أو أحدث وnpm:

```powershell
npm install
npm start
```

بعدها افتح `http://localhost:3000`. في أول تشغيل أنشئ حساب المدير من صفحة إعداد النظام. راجع [دليل المسؤول والتشغيل](docs/دليل-المسؤول-والتشغيل.md) لتفاصيل تشغيل الشبكة وتطبيقات Windows والبيانات والنسخ الاحتياطي.

## نطاق الوثائق

تصف هذه الوثائق السلوك الظاهر في التطبيق الحالي. وهي لا تعني أن قاعدة البيانات أو مرفقاتها مشفّرة، ولا تستبدل سياسة النسخ الاحتياطي أو ضوابط أمن الشبكة المعتمدة في الجهة.
